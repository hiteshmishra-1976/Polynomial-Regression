# 🔢 Polynomial Regression Analyzer

A Python-based machine learning project that implements **Polynomial Regression** 
from scratch with a **Tkinter GUI** to load CSV datasets, auto-detect the best 
polynomial degree, and visualize model performance.

---

## 📌 Features
- Custom Polynomial Regression model (no sklearn model used — built from scratch)
- Auto-detects the best polynomial degree (1 to 4)
- Tkinter GUI — load any CSV file and select target column
- Visualizes: Actual vs Predicted graph + Residuals plot
- Metrics: R², MSE, RMSE, MAE

---

## 🛠️ Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn (train_test_split only)
- Tkinter (GUI)
