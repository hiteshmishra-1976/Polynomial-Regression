# 🔢 Polynomial Regression Analyzer

A Python-based machine learning project that implements Polynomial Regression 
with a Tkinter GUI to load CSV datasets, auto-detect the best polynomial 
degree, and visualize model performance.

---

## 📌 Project Description

Polynomial regression is an extension of linear regression that models 
the relationship between variables as an nth-degree polynomial. This project 
builds a custom Polynomial Regression model from scratch (without using 
sklearn's regression model) and wraps it in a desktop GUI application.

The app allows users to:
- Load any CSV dataset
- Select a target column (Y variable)
- Automatically find the best polynomial degree
- View performance metrics and graphs
